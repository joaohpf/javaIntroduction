# Java Learning Repository ☕️

**Author:** João Henrique Porfirio Firmiano

Welcome to my **Java Learning Repository**!  
This repository contains Java exercises organized by topic and difficulty. It is designed to track my progress and practice coding in a structured way.

## Problem

I was learning Java from scratch and needed steady practice, plus a way to see my own progress over time.

## Solution

I wrote short exercises, one topic per folder, from simple output to user input and control flow. I did **not** use AI to write the exercises, because the goal was to learn by typing the code myself. **Claude (Anthropic)** was only used later to organize and translate this README.

## Technologies

- Java (JDK 11+)
- `Scanner` for console input
- Git and GitHub
- Claude (Anthropic): README only

## Demo

Console exercises, with no published demo. Each file runs on its own in the terminal (see [Repository](#repository)).

## Result

- 13 exercises, from `System.out.println` to `if/else` decisions.
- More than 40 commits that show the learning progression step by step.

## Repository

- **Code:** `fundamentos/` (see [Repository Structure](#repository-structure)).
- **Run** any exercise with Java 11+:

```bash
git clone https://github.com/joaohpf/javaIntroduction.git
cd javaIntroduction
java fundamentos/variables/Example01.java
```

## Repository Structure

- **fundamentos/** – Fundamental Java exercises  
  - **praticar-println/** – Basic output exercises using `System.out.println`  
  - **use-scanner/** – Exercises using `Scanner` for user input  
  - **variables/** – Exercises to practice variables, types, and assignments
  - **control-flow/** - 

Each folder contains multiple `.java` files, gradually increasing in complexity, so you can see the learning progression.

## How to Use

1. Open each `.java` file to study or run the code.
2. Feel free to clone or download the repository to practice on your own computer.

## Goals

- Learn and reinforce Java fundamentals
- Practice basic input/output and variable handling
- Gradually increase coding complexity
- Build a portfolio of practice exercises
